# Deltanyarune

2D RPG в духе Undertale / Deltarune на Godot 4.5: пошаговые бои с bullet-hell-фазами,
система TP и пощады (mercy), души разных типов, инвентарь с экипировкой, диалоги
с озвучкой и overworld с комнатами.

## Запуск

1. Установить [Godot 4.5](https://godotengine.org/) (стандартная сборка, не .NET).
2. Открыть `project.godot` в редакторе.
3. F5 — игра запускается с титульного экрана.

Рендер — `gl_compatibility`, разрешение 640×480 с целочисленным масштабированием,
ограничение 60 FPS.

## Управление по умолчанию

| Действие | Клавиша |
|---|---|
| Подтвердить / взаимодействовать | `Z` |
| Отмена / назад | `X` |
| Движение | стрелки или `WASD` |
| Инвентарь | `I` |
| Меню | `C` |
| Настройки | `Esc` |
| Полный экран | `F11` или `Ctrl+F` |

Клавиши можно переназначить в настройках игры, геймпад поддерживается
для движения и кнопок подтверждения/отмены.

## Структура проекта

- `fighters/` — боевые персонажи (`Character`) и монстры (`Monster`), их акты, спеллы и атаки.
- `soul/` — душа игрока, типы душ и поведения (bullet-hell часть).
- `pellets/` — пули и снаряды.
- `holdables/` — предметы, экипировка и логика их использования.
- `ui/` — боевой интерфейс, инвентарь, магазины, меню и настройки.
- `globals/` — автолоады: `Global`, `PartyData`, `Sounds`, `SceneTransition`,
  `PostProcessing`, `OverworldParty`.
- `resources/` — ресурсы диалогов, магазинов и прочих конфигов.
- `scripts/overworld/` — движение по миру, триггеры, камера, диалоги.
- `scenes/` — бой, комнаты мира, меню и общие префабы.
- `docs/` — документация по доменам.

Подробное описание — в [docs/ProjectStructure.md](docs/ProjectStructure.md).

## Ассеты, которых нет в репозитории

Музыка и звуковые эффекты лежат в `globals/sounds/music/` и
`globals/sounds/sound_effects/`, но эти папки исключены из git (`.gitignore`).
Для полноценного запуска со звуком их нужно положить туда вручную.
Озвучка персонажей (`globals/sounds/voices/`) в репозитории есть.

## Сохранения

Три слота, JSON-файлы в пользовательской папке Godot
(`user://save_0.json` … `user://save_2.json`), для этой сборки — каталог
`Deltanyarune_1.0`.

## Сборка

Готовый пресет экспорта — `export_presets.cfg` (Windows Desktop, x86_64).
Собранные `.exe`/`.pck` в репозиторий не коммитятся (см. `.gitignore`).
